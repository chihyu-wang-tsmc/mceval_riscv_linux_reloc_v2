# mceval_riscv_linux_reloc_v2

**Source:** HuggingFace dataset [`adpretko/mceval_riscv_linux_reloc_v2`](https://huggingface.co/datasets/adpretko/mceval_riscv_linux_reloc_v2) (community dataset)
**Downloaded:** 2026-10-23

The same 50 McEval C tasks (`C_1`…`C_50`) compiled for **riscv64 Linux**. Splits `O0` / `O2`, 50 each = **100 rows**.
Same field layout as the arm64 set: `source_code` plus `compiler_asm`, `object_asm`, `shared_asm`, `program_asm`, `compiler_pic_asm`, `pic_object_asm`, `program_asm_v2`.

Companions: [`mceval_arm_linux_reloc_v2`](https://github.com/chihyu-wang-tsmc/mceval_arm_linux_reloc_v2), [`mceval_x86_linux`](https://github.com/chihyu-wang-tsmc/mceval_x86_linux).
